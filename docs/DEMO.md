# 三分钟演示路线

1. 打开数据与实验，加载一个已保存的真实实验，说明固定观察池和研究模式。
2. 回测结果看策略与两类同池基准、市场参考，解释收益为负也如实展示。
3. 选择一个决策日期，到交易复盘查看指标、排名和目标。
4. 选择一只股票，查看K线、买卖点、订单编号和分批计划；说明为什么目标不等于实际成交。
5. 回到工作台修改滑点或批次间隔，保存为新实验。在后台运行时仍可浏览旧实验。
6. 策略对比选择原实验和新实验，检查配置差异；展示固定2022年验证集参数网格入口。
7. 导出ZIP，离线打开HTML报告，检查配置、数据hash和交易CSV。

断网时可使用已缓存真实快照；没有真实快照时创建明确标注的合成演示。不要把合成结果当作投资研究成果。
